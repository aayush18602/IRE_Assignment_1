# Q2 vs Q3: BM25 vs. embedding-based candidate retrieval

Full test-split runs, `n_recent=10` (query/user embedding built from each user's 10 most
recent clicks, strictly before the impression's own timestamp -- see `feature_store.
recent_history_asof`). Raw JSON per run in this directory; generated by
`scripts/compare_retrieval.py --dataset {ebnerd,mind}`.

## EB-NeRD (71,631 test impressions, 20,738 articles)

| K | BM25 | Embeddings (xlm-roberta-base, mean-pooled) | winner |
|---|---|---|---|
| 50  | 0.49% | 0.26% | BM25 |
| 100 | 1.03% | 0.48% | BM25 |
| 200 | 2.01% | 0.95% | BM25 |

Cold-start rate: 0% both (EB-NeRD's history table always has at least some pre-period clicks
for every user in this split).

## MIND (34,519 test impressions, 65,238 articles)

| K | BM25 | Embeddings (xlm-roberta-base, mean-pooled) | winner |
|---|---|---|---|
| 50  | 0.45% | 0.09% | BM25 |
| 100 | 0.82% | 0.17% | BM25 |
| 200 | 1.43% | 0.37% | BM25 |

Cold-start rate: 3.0% both (1,052 / 34,519 impressions -- users with no usable history as-of
their impression time; BM25 and embeddings hit the exact same cold-start population since both
derive their query/user-vector from the same `recent_history_asof` call).

## Reading

BM25 beats the raw embedding baseline on every K, on both datasets -- by ~2x on EB-NeRD and
~4-5x on MIND. This is a real, expected finding, not a bug: `xlm-roberta-base` here is a
**vanilla pretrained** transformer, mean-pooled with no fine-tuning for semantic similarity or
retrieval. It's well documented in the literature that raw BERT/XLM-R pooled embeddings are a
weak retrieval baseline compared to lexical methods -- this is exactly why models like
Sentence-BERT exist (fine-tuned specifically to make pooled embeddings useful for retrieval).
Absolute recall is low for both methods on both datasets (title-history-based candidate
generation against a 20K-65K article catalog is a genuinely hard problem at this scale), but the
BM25-over-embeddings gap is the headline comparison result for Q3.5 / the design note (Q6).
